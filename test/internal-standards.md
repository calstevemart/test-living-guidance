# Internal Standards

### Best Practices&#x20;

1\.     If internal standards are used, report clearly which internal standard(s), supplier, catalogue number,  their concentrations(s) and which purpose(s) they are used for. If isotopically-labelled internal standards are used, isotopes labelled and level of labelling should be defined. (eg 13C6-glucose).

2\.     Real-time monitoring of internal standards can be useful to detect and address issues in all samples during the run (e.g. missing vial, poor injection, degradation of LC-MS performance such as signal drift, retention time shifts, etc.).

3\.     Internal standards should not be used for semi-quantification for compounds that are other than their natural abundance equivalents.

4\.     Use internal standards added prior to sample preparation (Recovery standards) to highlight technical errors that occur during sample preparation and analysis using pre-defined acceptance criteria.

5\.     Use internal standards added post sample preparation to highlight technical errors during analysis only using pre-defined acceptance criteria.

6\.     Re-optimize internal standard selection and spiking concentration for each new sample matrix to ensure relevance of selected internal standards, no interferences  and suitable concentration level for matrix of interest.

7\.     Run at least one pooled QC replicate without spiking of internal standards to verify that no interferences arise from study samples.

8\.     Run at least one internal standard only sample in order to be able to assess matrix interference with internal standards.
